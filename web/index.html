Build a drill

Train deliberately

Start at a rate where you can keep an even rhythm. Use a short A/B loop and aim for consistent accuracy before raising the rate.

  • Jacks — repeated notes, changing columns every 8 notes.
  • Trills — alternate the outer columns.
  • Chordstream — streams mixed with two-note chords.
  • Long notes — hold control inside a stream.

Generated drills include a metronome track. Density values are note counts, not a difficulty rating.

MAKE IT YOUR INSTRUMENT

Controls & calibration.

Saved on this device. Applied to your next run.

Input

Click a key, then press its replacement. Duplicate lane bindings are rejected. Esc, Enter, P, R, arrows, [ and ] are reserved.

Positive values compensate for late inputs. Use the results screen to apply your measured average.

Timing & audio

Trainer scoring: 1,000,000 normalized points. Hold heads and tails count separately. The lazer profile matches OD-based note windows and release lenience. Score totals and hold-body bookkeeping remain trainer-specific.

Pitch preservation uses the browser's media playback engine. Disabled uses decoded Web Audio for tighter scheduling.

Playfield & skin

Scroll speed 1–40 uses osu!lazer’s travel-time scale. Higher is faster. F3 / F4 or Ctrl + / − adjusts speed during play.

Practice defaults

Tab skips to two seconds before the next note. It never skips taps or holds, and preserves the current score.

Practice loops save separate attempts. Autoplay and replay playback never create scores.

Data

Charts, audio, preferences and replays live in IndexedDB on this browser and origin. Back up your library before clearing browser data or changing devices.

REFERENCE

A proper practice workflow.

Import & play

  1. Browse and select a map in Online maps, or import a .osz archive, or a folder containing native mania .osu charts and their audio. Multiple difficulties share audio.
  2. Choose a chart. Set rate, modifiers and chart-specific offset. Check your bindings in Settings.
  3. Use Play for a full run, or Practice for an A/B section. Click the density graph to set A; Shift-click to set B.
  4. Review timing scatter, histogram, lane accuracy and the weakest section. Save a replay or practice the weakest section directly.

What is supported

Native osu!mania 1–10K charts, tap and hold notes, timing points and inherited scroll velocities, archive audio/backgrounds, local chart library, favorites, collections, search, pattern drills, custom timing windows, skins, variable rate, A/B loops, score history, input replays and library backups.

Lazer timing profile

The lazer profile uses native mania OD-dependent windows, rate-aware rounding, a separate miss window, 1.5× hold-tail release lenience and a Meh cap after a hold break. Original osu!lazer: ManiaHitWindows and hold-tail rules. Full score, health, body ticks and all client mechanics are not emulated.

Cache & connection

Use Cache for offline play on a server chart before disconnecting. Media is hash-verified, stored in IndexedDB, and reused without a network fetch. Cache budgets evict least-recently-used media; browser storage can also be cleared or evicted. The app shell is cached after an authenticated visit. Offline copies do not grant server access or bypass sign-in, provider limits, firewalls or network blocks. Settings → Cache has usage and connection checks.

Mania skin import

Settings → Appearance → Import osu! skin accepts legacy .osk packs (or ZIP). Per-mode KeyImage/NoteImage mappings, @2x PNGs, animation frames, hold sprites, idle/pressed receptors, stage pieces, judgments, a normal hit sample, widths, gaps, flip options and hit position are supported. See the osu!mania skin reference. Imports stay local and persist in this browser. Original skin packs should be kept separately; library backups currently do not include skin packs.

Not every native skin feature is emulated: trainer menus and fonts stay intact, the playfield stays centered, and extra/unsupported ini values are listed on import. Standard-only skins lack mania sprites. Current safe limits are 80 MB compressed, 128 MB expanded and 24 megapixels of decoded playfield sprites.

Skipping

Use the Skip button or Tab in a long empty intro or break. Space also works when Space is not a lane binding. Skips preserve score and combo, leave two seconds of reading time, and never cross taps or active long notes. Skip events are saved with trainer replays. Automatic intro skipping can be enabled in Practice settings.

Current limits

This is an independent browser trainer, not a full Interlude or Quaver replacement. No online rankings, multiplayer, chart editor, .osr replay import, Quaver import, keysounds, storyboards, or official scoring compatibility. Standard-mode charts are not converted to mania.

Imported audio must be decodable by your browser. Keyboard rollover, audio latency and background-tab throttling depend on your hardware/browser. The game automatically pauses when focus is lost.

Use charts you have permission to use. Local imports stay local. Maps selected in Online maps are fetched and stored by the server.
